北陸戦士しろみぶり BEEF OR FISH（分割版）
================================================

起動方法
------------------------------------------------
このフォルダで serve.py をダブルクリック（または
`python serve.py` / `python3 serve.py`）すると、ローカル
サーバーが起動してブラウザが自動で開きます。
URL は http://localhost:8000/（ポートは引数で変更可）。

なぜ専用サーバーが要るのか：モデル（models/model.vrm）を
Range リクエストで分割取得するため、標準の http.server
では足りません。同梱の serve.py が Range 対応版です。
index.html をダブルクリックで直接開く方式（単一ファイル版）
は節目ビルドでのみ生成します。

------------------------------------------------
  index.html            ゲーム本体（プログラム）
  data/stage_data.js    ステージ・小物・ミッションのデータ
  data/units.js         敵の種類・性格・難易度のデータ
  data/db/characters.json キャラ定義の正データ（v94〜。編集するのはこちら）
  data/generated/chars_data.js 上記から自動生成される実行用データ（編集禁止）
  models/model.vrm      ぶりのモデル
  img/title.jpg         タイトル画像
  img/controller_map.png 操作配置図
  audio/bgm/            BGM（利用者が置く。同梱されない）
  audio/voice/          ボイス（利用者が置く。同梱されない）
  audio/sfx/            効果音（44ファイル）
  three.min.js          Three.js ライブラリ
  serve.py              Range 対応ローカルサーバー
  README.txt            このファイル
  CHANGELOG.md          版ごとの変更履歴

BGMについて（重要）
------------------------------------------------
BGMの mp3 は配布物に同梱されません。お手持ちの音源を、
audio/bgm フォルダに以下の名前で置いてください。

  bgm01.mp3   タイトル
  bgm02.mp3   通常戦闘
  bgm03.mp3   ボス戦
  bgm_win.mp3   勝利
  bgm_lose.mp3  敗北

無い場合は無音で動作します（エラーにはなりません）。
設定画面の BGM 状態表示が「ファイルが見つかりません」
となり、置いた曲だけが再生されます。ボス曲（bgm03）が
無い場合は通常戦闘曲で代用されます。
配布 zip を上書き展開しても、既存の BGM ファイルが
消えたり上書きされたりすることはありません。

更新の受け方
------------------------------------------------
通常の更新は index.html と data/ の差し替えだけで済みます。
他のファイル（モデル・音源・画像）は変わりません。

データの編集
------------------------------------------------
敵の数値やステージの値は data/ の JS ファイル側にあります。
JSON ではなく普通の JavaScript なので、そのまま編集して
ブラウザを再読み込みすれば反映されます。
